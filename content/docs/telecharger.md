# Télécharger le cours en livre

Le contenu du cours est aussi offert sous forme de deux livres, pour une lecture
hors ligne, sur papier ou sur liseuse. Ils sont produits automatiquement à chaque
mise à jour du site, et contiennent donc toujours la même version que les pages en
ligne. La date de production figure sur la page de titre.

- <a href="{{< rel "/telechargements/INF1410-genie-logiciel.pdf" >}}">**Livre PDF**</a>&nbsp;:
  un livre mis en page, avec une table des matières et des liens internes,
  pour l'écran ou l'impression.
- <a href="{{< rel "/telechargements/INF1410-genie-logiciel.epub" >}}">**Livre EPUB**</a>&nbsp;:
  un livre numérique dont le texte s'adapte à l'écran, pour une liseuse ou une
  application de lecture.

Les blocs de code exécutables, les applets interactives et les vidéos ne peuvent
pas être intégrés à ces livres. Le code y est reproduit tel quel, et chaque
élément interactif est accompagné d'un lien vers la page du site où il se trouve.
