{{/* layouts/shortcodes/illustration.html Insère un SVG de assets/illustrations/ directement dans la page, plutôt que de le référencer par . C'est la condition pour que le trait, dessiné en currentColor, suive le thème, et pour que les variables d'accent définies dans assets/styles/custom.css l'atteignent. L'enveloppe reprend la structure du shortcode image du thème, une étiquette et une case à cocher masquée, pour que l'agrandissement au clic fonctionne comme sur les autres images du cours. Le CSS du thème ne vise que les balises img, custom.css double donc ses règles pour les svg insérés. Usage : {{< illustration src="worse-is-better.svg" legende="..." >}} */}} {{- $src := .Get "src" | default (.Get 0) -}} {{- $id := printf "illustration-%d" .Ordinal -}} {{- with resources.Get (printf "illustrations/%s" $src) -}} {{- else -}} {{- warnf "illustration : assets/illustrations/%s introuvable" $src -}} {{- end -}}
